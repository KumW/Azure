# Azure SQL Deployment Scripts

This folder contains Azure CLI (Bash) scripts for deploying and managing Azure SQL resources.

## Contents

### SQL Server
Scripts for:
- Creating Azure SQL Servers
- Configuring firewall rules
- Managing administrative settings

### SQL Database
Scripts for:
- Creating Azure SQL Databases
- Configuring performance tiers and service objectives
- Managing database settings

## Prerequisites

Before running the scripts, ensure:

- Azure CLI is installed
- You are authenticated to Azure

```bash
az login
